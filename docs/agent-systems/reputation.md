# Reputation System

This document defines the Lodge's merit and honor layer.

## Core principles

- Chivalry is permanent.
- Leaderboards are views, not the source of truth.
- Ember is a merit balance.
- SOLCOT is a treasury / accounting unit until a real payment flow exists.

## What should be tracked

- member handle
- room
- Ember balance
- SOLCOT balance
- acts of chivalry
- whether the member is whitelisted

## What should be public

- summary totals
- top members
- room participation
- quest status

## What should remain steward-controlled

- reward amounts
- manual seals
- access tiers
- claim verification

## Good UI pattern

- show the totals first
- show the leaderboard second
- show the permanent record third
- show the proof / handoff surface last
